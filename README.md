# ResumeNext plugins for Claude

Resume, cover letter and job application tools for Claude, each a plugin that connects to a ResumeNext MCP server. No account is needed to use the tools.

- [ATS Resume Checker & Resume Builder - ResumeNext](./resumenext-ats-resume-checker): Check a resume's ATS score, see what to fix first, and open it in the ResumeNext resume builder with templates and a live score.
- [Job Match & Resume Keyword Scanner - ResumeNext](./resumenext-job-match): Compare a resume with a job description: matched and missing keywords, coverage, and a job-tailored ATS score.
- [Cover Letter Checker & Builder - ResumeNext](./resumenext-cover-letter): Check a cover letter against a fixed checklist, read example letters by role, and open the final letter in the ResumeNext cover letter editor.
- [Resignation Letter Generator - ResumeNext](./resumenext-resignation-letter): Write a resignation letter in a standard, formal or grateful style and open it in ResumeNext to edit and save as PDF, DOCX or TXT.
- [LinkedIn Profile Review & Resume Converter - ResumeNext](./resumenext-linkedin-resume): Review the text of a LinkedIn profile section by section and turn it into a resume that opens in the ResumeNext editor.
- [Resume Examples & Templates - ResumeNext](./resumenext-resume-examples): Browse resume examples by role and resume templates, each with a link that opens it in the ResumeNext editor as a starting point.

Documentation: https://resumenext.io/mcp
